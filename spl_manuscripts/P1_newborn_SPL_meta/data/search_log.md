# Search log: stretched penile length (SPL) in healthy newborn boys

- **Database:** PubMed/MEDLINE, accessed through the PubMed MCP tools (`search_articles`, `find_related_articles`, `get_article_metadata`, `get_full_text_article`). No other databases (Embase, Scopus, Web of Science, LILACS, CNKI, African Index Medicus, grey literature) were searched. That is a limitation to report.
- **Date of all searches:** 2026-11-18. No date, language or publication-type limits were applied.
- **Screening:** a single reviewer (an AI agent) screened all records and extracted the data. There was no second reviewer, so independent duplicate screening and extraction is still needed before publication.
- **Full text:** full text was obtained only through PubMed Central (PMC). Records without a PMC copy were assessed on the abstract alone. They were included as `abstract_only` when the abstract reported n and a central value for an eligible sample.

## 6. Duplicate and overlapping cohorts handled

- Singal 2015 (retained) and Jain 2013 (excluded) report the same Navi Mumbai cohort.
- Shah 2020 (retained) and Chin 2021 (excluded) report the same IFED cohort, Philadelphia.
- Celik 2025 BMC Pediatr (retained) and Celik 2025 Toxics (excluded) report the same Hacettepe NICU cohort.
- Romano-Riquer 2007 and Longnecker 2007 (PMID 17272288, excluded at screening) report the same Chiapas cohort.
- Six reports come from the Cambridge Baby Growth Study (Thankamony 2009/2013, Fisher 2016/2020, Kung 2020, Acerini 2009). It used a flaccid method, so all were excluded.
- Boas 2006, Koskenniemi 2018, Mau Kai 2007 and Main 2006 come from the Danish–Finnish cohort. Only Boas 2006 is in the extraction, flagged INCOMPLETE.
- Asafo-Agyei 2017 SPL and Asafo-Agyei 2017 AGD (excluded) report the same Kumasi cohort.
- Kareem 2020 PAMJ (SPL, retained) and Kareem 2020 JPEM (AGD, excluded) report the same Ile-Ife cohort.
- Wang 2018 and Yi 2017 report the same Chongqing cohort. Both were excluded.
- Matsuo 2014 and Ishii 2014 both come from Keio University, Tokyo, so the cohorts may overlap. Ishii was not retrieved.

## 7. Notes on data handling

- Values in mm were converted to cm only by exact division by 10, and every such row says so in `notes`.
- No SDs were imputed. Where a source table gives mean ± k·SD but is internally inconsistent (Soheilipour 2018 preterm bands), SD was left blank.
- Every number has a verbatim quote in `verbatim_quote`. All of them were copied from text retrieved in this session.
- Non-arithmetic central values are flagged in `notes` (for example, Roy 2019 reports a 5% trimmed mean).
