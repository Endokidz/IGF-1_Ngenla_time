## Notes on verification

- **Print year vs PubMed e-pub date.** The PubMed record date is the e-pub date for some articles. For these the citation uses the print/issue year, which was confirmed by a PubMed publication-date-filtered search of the PMID: Barnett2005 (e-pub 2004; 34(1) is 2005), Cole2021 (e-pub 2020; 30(2) is 2021), Luo2018 (e-pub 2016; 27(6) is 2018), Harris2009 (e-pub 2008; 42(2) is 2009). Bouvattier: PubMed has **2011** only, and a 2012 date filter does not match it, so the key and citation use 2011 (vol 8(3)).
- **Lee2006**: PMID 16882788 is the full Pediatrics statement with Lee as first author (e-pages e488-500). Related versions in PubMed: the Pediatrics print summary (Houk CP first; 118(2):753-7; PMID 16882833; doi:10.1542/peds.2006-0737) and the Arch Dis Child version (Hughes IA first; 91(7):554-63; PMID 16624884; doi:10.1136/adc.2006.098319). The record's collective author is not listed in the author string because its full name could not be confirmed. The title as PubMed gives it already names the conference.
- **SPIRIT 2025 exists.** It was published at the same time in five journals. The BMJ version is given above (Chan2025). The co-publications in PubMed are: Lancet 2025;405(10491):e19-e27 (PMID 42290521; doi:10.1016/S0140-6736(25)00770-6); JAMA 2025;334(5):435-443 (PMID 40294593; doi:10.1001/jama.2025.4486); Nat Med 2025;31(6):1784-1792 (PMID 40295741; doi:10.1038/s41591-025-03668-w); PLoS Med 2025;22(4):e1004589 (PMID 40294521; doi:10.1371/journal.pmed.1004589). All have 39 authors and Chan AW is first author.
- **WHO2006**: the corporate author "WHO Multicentre Growth Reference Study Group" was confirmed by a PubMed [Corporate Author] search that returns PMID 16817681.
- **vonElm2007 / Guyatt2008 / Borghi2006**: each record also has a group author. "et al." covers it.
- **Higgins2009** *is* indexed in PubMed (PMID 19381330).
- **Johannsen2018**: the exact title is confirmed as given (JCEM 2018;103(8):3028-3037).
- **Busch2022** (optional item): this is the best Busch-first match for 2022–2025. It gives reference curves for minipuberty reproductive hormones and reports testicular volume. It does **not** report penile length. It comes from the COPENHAGEN Minipuberty Study. A related genital reference with Busch as co-author, not first author, is Fischer MB et al. *Anogenital Distance in Healthy Infants: Method-, Age- and Sex-related Reference Ranges*. J Clin Endocrinol Metab. 2020;105(9):2996-3004 (PMID 32574349; doi:10.1210/clinem/dgaa393). It is outside the 2022–2025 window and was not added as a keyed row.
- **Item 29 (gonadotropin infusion in infants)**: all three candidate papers exist and are verified (Papadimitriou2019, Stoupa2017, Lambert2016). The PubMed tools cannot check citation counts, so the "most-cited" ranking was not checked.
